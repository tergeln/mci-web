# Website illustrations

Generated with the built-in Imagegen tool on 25 October 2026. These are concept illustrations, not documentary photographs. The supplied Khush Tugul planting photographs remain unchanged.

The original PNG outputs remain in the tool's generated-images directory. Project assets are encoded as JPEG without compositional edits, with a 1536 × 1024 version and a 768 × 512 version for responsive loading. Image metadata lives in `src/assets/siteImages.js`; course and news images are returned through the existing API functions.

## Shared final prompt

Use case: stylized-concept. Asset type: landscape website card illustration in a coherent educational technology image set. Subject: {subject}. Premium restrained 3D editorial illustration, tactile matte ceramic and frosted glass, deep navy and periwinkle blue with small muted warm gold accents, soft pale blue-gray studio background, refined natural contact shadows, gentle studio light. Clear central composition, generous breathing space, key objects within the central 70% so the image works in wide and square crops. Wide landscape 3:2 composition. No readable text, no letters, no numbers, no logos, no watermarks, no brand marks, no people, no collage panels, no photorealistic event photography. One cohesive scene.
