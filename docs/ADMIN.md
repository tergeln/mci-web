# Админ удирдлага

`/admin` нь зөвхөн admin эрхтэй demo бүртгэлд нээгдэнэ. Одоогийн хувилбар нь хөтөч дээр ажилладаг demo: өөрчлөлтийг localStorage-д хадгалдаг бөгөөд бүх зочинд хуваалцах серверийн өгөгдлийн сантай холбогдоогүй. Нийтлэх гэдэг нь энэ хөтөчийн нийтэд харагдах нүүр, сургалтын каталог, мэдээний хуудсанд гаргахыг хэлнэ.

## Боломжууд

- Тойм: сургалт, элсэлт, суралцагч, шинэ хүсэлт, хугацааны график.
- Сургалт: нэмэх, засах, хуулбарлах, үнэ/чиглэл/түвшин/хугацаа/элсэлтийн төлөв өөрчлөх; нүүр хуудсанд онцлох.
- Мэдээ: гарчиг, ангилал, товч ба дэлгэрэнгүй агуулга, огноо, байршил, хамтрагчид, зураг ба нэмэлт зургууд.
- Мэдээ болон сургалтыг ноорог, нийтэлсэн, архивласан төлөвт шилжүүлэх. Ноорог ба архив нийтэд харагдахгүй.
- Устгахын өмнө баталгаажуулна. Устгасан мэдээлэл тусдаа жагсаалтад хадгалагдаж, сэргээх боломжтой. Бүрмөсөн устгах үйлдэл байхгүй.
- Элсэлт ба захиалга: холбоо барих мэдээлэл, дэлгэрэнгүй, хайлт, хугацаа, шинэ/шийдвэрлэсэн/цуцалсан төлөв; устгах, сэргээх.
- Хэрэглэгчид: хайх, эрхээр шүүх, нэр/утас/суралцах зорилго засах, элсэлт ба захиалгын түүх харах. Эрх болон нууц үг өөрчлөх боломж оруулаагүй.
- CSV: сургалт, мэдээ, элсэлт, захиалга, хэрэглэгчийн шүүсэн жагсаалт. UTF-8 BOM, ишлэл ба томьёоноос хамгаалах escaping ашиглана.
- Үйлдлийн түүх: мэдээ, сургалтын сүүлийн 150 өөрчлөлт.

Монгол текст заавал; англи талбар хоосон бол монгол хувилбарыг ашиглана. Зургийг холбоосоор эсвэл PNG/JPG/WEBP/GIF файлаар (1 MB хүртэл) оруулна. Хадгалах зай хүрэлцэхгүй бол алдаа харуулж, өмнөх мэдээллийг хэвээр үлдээнэ.

## Хадгалалт

| Түлхүүр | Агуулга |
| --- | --- |
| `mc-managed-content-v1` | Мэдээ, сургалт, үйлдлийн түүхийн нэг атомик JSON баримт |
| `mc-demo-records` | Нүүр хуудсаар ирсэн элсэлт болон хэрэглэгчийн элсэлт/захиалга |
| `mc-profile-<userId>` | Нэр, утас, суралцах зорилго |

Үндсэн мэдээ, сургалтын seed нь `src/api/mock/db.js`. Нүүр хуудсын эх загвар `src/data/courses.js`-оос нийлүүлэгдэнэ. Админаар зассан сургалт canonical title/description/image-ийг ашиглана. `featured` нь нүүр хуудсанд харагдах эсэхийг тодорхойлно. Нийтлэгдээгүй/устгасан мэдээллийг public API буцаахгүй. Нээлттэй хуудас өөрчлөлтийг custom event, өөр tab нь storage event-ээр дахин татна.

## Сервер холбох гэрээ

`VITE_USE_MOCK=false` үед дараах API дуудлага илгээнэ. Эдгээр серверийн endpoint одоогийн repository-д хэрэгжээгүй. Бодит сервер нэвтрэлт, admin эрхийг өөрөө баталгаажуулах ёстой; demo session ID нь хамгаалагдсан серверийн нэвтрэлт биш.

| Арга | Зам | Зориулалт |
| --- | --- | --- |
| GET | `/api/admin/courses`, `/api/admin/news` | Ноорог, архив, устгасан мэдээллийг хамруулсан бүтэн жагсаалт |
| POST | `/api/admin/courses`, `/api/admin/news` | Нэмэх; бүтэн хадгалсан объект буцаана |
| PUT | `/api/admin/courses/:id`, `/api/admin/news/:id` | Засах; бүтэн хадгалсан объект буцаана |
| POST | `/api/admin/:type/:id/:action` | `published`, `draft`, `archived`, `delete`, `restore` |
| GET | `/api/admin/activity` | `{ id, action, type, title: LocalizedText, at: ISODate }[]` |

Мэдээний нийтлэлд `body.mn`, `body.en` шаардлагатай. Хоёр төрлийн нийтлэлд `publication`, `createdAt`, `updatedAt`, `deletedAt` орно. Сургалтад `featured`, `duration`, `level` нэмэгдсэн. Public `/courses`, `/courses/:id`, `/news`, `/news/:id` нь зөвхөн нийтэлсэн, устгаагүй объект буцаана. Элсэлт, захиалга, хэрэглэгчийн demo удирдлагыг бодит серверт шилжүүлэх ажлыг тусад нь хэрэгжүүлэх шаардлагатай.

## Шалгалт

`npm run build`

`node --test src/api/mock/contentStore.test.js src/context/demoAccounts.test.js src/pages/Account/adminAnalytics.test.js src/components/Chatbot/chatViewport.test.js src/components/canvas/particleLayout.test.js`

Хөтөч дээр сургалтын ноорог → нийтлэх → засах → каталог/нүүр дээр харах → устгах → сэргээх, мэдээ нийтлэх → дэлгэрэнгүй харах, шинэ сургалтад элсэх → админд харах → төлөв шинэчлэх → дахин ачаалах, хэрэглэгчийн мэдээлэл засах болон 390 px маягтын багталтыг шалгасан.
